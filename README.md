A one-line joke about working beside an AI coding agent. The program writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if unset) — deterministic, no dependencies, no network.

## Run

```sh
node main.ts
```

## The joke

> My AI agent ran the demo, fixed three bugs, introduced seven, and took credit for all ten.
